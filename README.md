## Abstract

### Abstract

The **Blood Bank Inventory and Donor Matcher** is a simple system designed to help manage blood group information and find suitable donors quickly. The main purpose of this project is to maintain donor details and check blood availability in an organized way. The system stores information such as donor name, blood group, contact details, and availability. When a blood request is received, it checks the required blood group and helps identify suitable donors. This reduces the time needed to search for donors manually and makes the process more organized. The project also helps in maintaining accurate blood stock information. Overall, the system provides a simple and efficient way to manage blood donors and blood inventory, which can be useful for blood banks, hospitals, and emergency situations.
